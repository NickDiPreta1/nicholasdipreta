# Nicholas DiPreta

A personal website and blog where I share my thoughts on AI Ethics, current readings, and other interests.

## About

This site serves as a space to explore and discuss topics I'm currently engaged with, particularly in the AI Ethics space. You'll find reflections on what I'm reading, emerging ethical considerations in artificial intelligence, and broader interests that capture my attention.

## Built With

This site is built with [Astro](https://astro.build), a modern web framework optimized for content-focused websites.

Features:
- Markdown & MDX support for writing
- SEO-friendly with canonical URLs and OpenGraph data
- RSS Feed support
- Fast performance and minimal styling

## Development

All commands are run from the root of the project:

| Command                   | Action                                           |
| :------------------------ | :----------------------------------------------- |
| `npm install`             | Installs dependencies                            |
| `npm run dev`             | Starts local dev server at `localhost:4321`      |
| `npm run build`           | Build your production site to `./dist/`          |
| `npm run preview`         | Preview your build locally, before deploying     |
| `npm run astro ...`       | Run CLI commands like `astro add`, `astro check` |
| `npm run astro -- --help` | Get help using the Astro CLI                     |
